Vigie on the M5Stack Tab5

The 5-inch tablet as a standalone alert display: the world map of current hazards, the five most severe and the weather of your zones, at 1280 × 720. ESPHome without Home Assistant: the screen fetches its data by itself, over Wi-Fi.

What the screen shows

The Waveshare 7B layout, scaled up by 20 % to fill the Tab5's sharper screen: the status bar (link to the API, date and time of the zone), the world map with hazards as dots coloured by severity, the five most severe with their distance and direction, and the weather panel of the zone. Touch the panel to go to the next zone.

Each part in detail, and what the screen does when the API stops answering: the Vigie alert display.

The three versions of the Tab5

M5Stack changed the chip that drives the display and the touch twice; each one is picked at build time.

  • ST7121 (since 2026-04-28): Vigie has run on one since 2026-10-28, Wi-Fi and data from the public API over HTTPS.
  • ST7123 (2025-10-14 to 2026-04-28): compiled, not yet run with Vigie on a tablet.
  • ILI9881C (the first one, 2025-05-09 to 2025-10-14): compiled, never run.

The chip is printed on the back of the tablet, above the Espressif logo; how to tell, and the traps: the versions of the Tab5.

The ESPHome configuration, without Home Assistant

No api: component: nothing links the screen to Home Assistant. Wi-Fi is given after the install (Improv over USB, or the access point the screen opens by itself), the data comes through http_request and LVGL draws it.

Below, a short, complete example on the same hardware base as Vigie: it shows the temperature and the weather warning of a place, read from the public Vigie API. Pick your Tab5's chip at the top of the file; change the latitude and longitude, or the address, to read another API.

Validated and compiled with ESPHome 2026.9.1 on 2026-10-28, not yet tried as is on the tablet: its hardware settings are those of Vigie display, which runs on a Tab5 ST7121.

The settings that matter on this tablet

  • The ESP32-C6, which carries the Wi-Fi, is powered through an I/O expander (PI4IOE5V6408, pin 0 of the second one): without the wifi_power switch turned on at start-up, the SDIO link never comes up ("sdmmc_card_init failed", seen on an ST7121 on 2026-10-28). Its reset, GPIO15, is active high.
  • The panel reset goes through the other expander, which needs a second after start-up: without the wait in on_boot, black screen after a software restart. It has to block, hence the C delay().
  • The panel is portrait (720 × 1280): LVGL turns it to landscape with rotation: 270, and turns the touches with it.
  • No mirroring on the display or the touch: it corrupts the picture on an ST7121.
  • The MIPI-DSI link is powered by LDO 3 of the ESP32-P4, at 2.5 V (esp_ldo).
  • The display model and the touch chip change with the version: M5STACK-TAB5-ST7123 or -ST7121 with the st7123 touch, M5STACK-TAB5 with the gt911 for the ILI9881C.

The full firmware

vigie.yaml puts packages together: the tablet hardware (board-tab5.yaml, power rails and charger included), the size of the screen, the world map and the fonts (layout-tab5.yaml), the LVGL screen, drawn in C++, and the API client: one request a minute, a frame refused if its size or checksum does not match.

Install Vigie

No published release to install from the browser yet: you build the firmware yourself. Allow half an hour, mostly for the first build.

  1. Install ESPHome 2026.9.1 or newer and get the vigie-display repository.
  2. Create a signing key: once installed, the screen only accepts updates signed with the same key. Keep a copy.
  3. Build for the Tab5: esphome -s vigie_board tab5 -s vigie_api_url https://vigie.auxfilsdesidees.fr -s vigie_signing_key vigie_signing_key.pem compile vigie.yaml. With an ST7121, add -s board_tab5_panel M5STACK-TAB5-ST7121; with an ILI9881C, -s board_tab5_panel M5STACK-TAB5 -s board_tab5_touch gt911 -s board_tab5_touch_interval never. Then install over USB with ESPHome or from ESPHome Web.
  4. Give it Wi-Fi over USB (Improv) or through the "Vigie setup" access point the screen opens after a minute. Within a minute, the status bar reads "Up to date".

Settings and common problems are in the installation guide. Later updates go over Wi-Fi. The same tablet as a Home Assistant display: the M5Stack Tab5.
