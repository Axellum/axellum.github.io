Vigie on the Waveshare ESP32-P4 7B

What the screen shows

The Vigie layout is drawn for this screen, to the pixel: the status bar (link to the API, date and time of the zone), the world map with hazards as dots coloured by severity, the five most severe with their distance and direction, and the weather panel of the zone. Touch the panel to go to the next zone.

Each part in detail, and what the screen does when the API stops answering: the Vigie alert display.

The ESPHome configuration, without Home Assistant

No api: component: nothing links the screen to Home Assistant. Wi-Fi is given after the install (Improv over USB, or the access point the screen opens by itself), the data comes through http_request and LVGL draws it.

Below, a short, complete example on the same hardware base as Vigie: it shows the temperature and the weather warning of a place, read from the public Vigie API. Change the latitude and longitude, or the address, to read another API.

Validated and compiled with ESPHome 2026.9.1 on 2026-10-28, not yet tried as is on the board: its hardware settings are those of Vigie display, which runs on mine.

The settings that matter on this board

  • ESPHome 2026.9.1 at least: 2026.9.0 crashes while setting up the display of ESP32-P4 revision 3 chips.
  • Wi-Fi goes through the ESP32-C6, linked over SDIO (esp32_hosted); its reset, GPIO54, is active high.
  • PSRAM at 200 MHz: at its default speed, the display dropped out about thirty times a second ("lcd.dsi underrun").
  • The GT911 touch has its reset on GPIO23, even though Waveshare's code says it is not connected, and it is mirrored in X and Y.
  • The backlight is an inverted output on GPIO32, at 5 kHz.
  • Picture direction: the panel is mounted upside down compared with its driver, hence rotation: 180 for a board the right way up, 0 for a board mounted upside down. Vigie display starts from 0, the way my board is mounted: add -s board_rotation 180 if the picture is upside down.
  • After a software restart, the link to the ESP32-C6 may not come back until a power cut. Vigie display turns every software restart into a reset of the whole digital core (c6_link.cpp); the example does not.

The full firmware

vigie.yaml puts packages together: the board hardware (board-waveshare-7b.yaml), the size of the screen, the world map and the fonts (layout-waveshare-7b.yaml), the LVGL screen, drawn in C++, and the API client: one request a minute, a frame refused if its size or checksum does not match.

Install Vigie

No published release to install from the browser yet: you build the firmware yourself. Allow half an hour, mostly for the first build.

  1. Install ESPHome 2026.9.1 or newer and get the vigie-display repository.
  2. Create a signing key: once installed, the screen only accepts updates signed with the same key. Keep a copy.
  3. Build: the 7B is the default board. esphome -s vigie_api_url https://vigie.auxfilsdesidees.fr -s vigie_signing_key vigie_signing_key.pem compile vigie.yaml, then install over USB with ESPHome or from ESPHome Web.
  4. Give it Wi-Fi over USB (Improv) or through the "Vigie setup" access point the screen opens after a minute. Within a minute, the status bar reads "Up to date".

Settings and common problems are in the installation guide. Later updates go over Wi-Fi. The same board as a Home Assistant display: the Waveshare 7B.
