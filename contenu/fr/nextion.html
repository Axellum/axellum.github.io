NextionWeather Météo-France

Le projet actuel, mis à jour en 2026. L'écran affiche la date et l'heure, le temps actuel, les risques de gel, de neige et l'indice UV, les prévisions sur 3 jours ou l'agenda sur 8 jours, l'heure par heure sur 8 heures, les vigilances et la pluie par tranches de 5 minutes, avec un réglage de la luminosité.

Il existe en plusieurs versions : avec Home Assistant (capteurs ESPHome, ou la version « service push » recommandée, sans capteurs intermédiaires), ou sans Home Assistant avec un programme Arduino qui interroge directement un service météo. Il fonctionne avec les écrans Nextion Basic, Enhanced et Intelligent.

Depuis mars 2026, tout le code et la présentation de ce dépôt ont été écrits par l'IA (Gemini). La version « service push » est en test ; les versions sans Home Assistant ne sont pas testées.

Les premières versions

Écran météo Nextion par ESPHome (2020)

Une version simplifiée pour l'écran de 3,5 pouces : prévisions sur 3 jours, 4 boutons d'interrupteurs et des scripts pour une ampoule de couleur.

Le dépôt

Meteo (2020)

Le tout premier, sur un Nextion NX4832T035 et un ESP32 ou ESP8266. Le code est en partie obsolète depuis le changement de l'API de Météo-France : à garder comme archive.

Le dépôt
