NextionWeather Météo-France

The current project, updated in 2026. The screen shows the date and time, the current weather, frost, snow and UV risks, a 3-day forecast or an 8-day calendar, the next 8 hours, warnings and rain in 5-minute steps, with a brightness setting.

It comes in several versions: with Home Assistant (ESPHome sensors, or the recommended "push service" version, with no intermediate sensors), or without Home Assistant with an Arduino program that queries a weather service directly. It works with Nextion Basic, Enhanced and Intelligent screens. The documentation is in French.

Since March 2026, all the code and the presentation of this repository have been written by AI (Gemini). The "push service" version is in testing; the versions without Home Assistant are untested.
