The Vigie alert screen

A touch screen that sits in the house and shows the disasters under way around the world and the weather of the places that matter to you. It stands on its own: no Home Assistant, no app, just Wi-Fi.

What the screen shows

The status bar

The link to the API (up to date, waiting, unreachable, with the age of the data), the date and time of the zone on screen.

The world map

Current hazards as dots coloured by severity (red, orange, yellow, green), and the zones you watch.

The five most severe

Earthquake, cyclone, volcano, flood, fire… with the magnitude when there is one, the source title, distance and direction from the zone on screen, and the age of the alert.

The weather

Current weather, wind and gusts, humidity, rain in the next hour, air quality, waves for coastal zones and a five-day forecast. Touch the panel to go to the next zone.

A value the API does not know is left off the screen, never invented.

Two boards, one firmware

The same code, set for the board at build time. The 7B layout is the reference, to the pixel; on the Tab5 it is scaled up by 20 % to fill its sharper screen.

Rendered from the firmware itself on a PC by continuous integration, with a live frame of the public API.

  • Waveshare 7B: tested on the board on 2026-10-20. See the 7B page.
  • M5Stack Tab5 ST7121: Vigie has run on one since 2026-10-28 (Wi-Fi, data from the public API over HTTPS).
  • Tab5 ST7123 and ILI9881C: compiled, never run on a real tablet. To find out which version you have: the Tab5 page.

Nothing to solder: a USB-C cable for power and the first install, Wi-Fi for the rest.

How it works

Every minute the screen asks the Vigie API for one compact frame; the API itself gathers the official and scientific sources. The screen never talks to the sources directly, nor to Home Assistant.

With the public API

The address https://vigie.auxfilsdesidees.fr, free but rate-limited and with no guarantee of service. The zones shown are the demo ones (Paris, Tokyo, Pointe-à-Pitre, San Francisco, Reykjavik in October 2026).

With your own API

The API runs on a PC, a NAS or a Raspberry Pi on your network, and the screen shows the zones you add to it.

Install it

No published release to install from the browser yet: you build the firmware yourself with ESPHome. Allow half an hour, mostly for the first build.

  1. Install ESPHome 2026.9.1 or newer (2026.9.0 crashes when the 7B's display starts) and get the vigie-display repository.
  2. Create a signing key: once installed, the screen only accepts updates signed with the same key. Keep a copy.
  3. Build with your board, the API address and the language, then install over USB with ESPHome or from ESPHome Web.
  4. Give it Wi-Fi over USB (Improv) or through the "Vigie setup" access point the screen opens after a minute. Within a minute, the status bar reads "Up to date".

Exact commands, settings and common problems are in the installation guide. Later updates go over Wi-Fi.
