What you will find

The world map

All current alerts, with a list filtered by level and type, then a page per country, per area and per alert, where the issuer's text is kept unchanged.

Near me

A place chosen by name, the browser's location or a click on the map. The place stays in the browser; only a position rounded to about 5 km goes to the server, for the weather.

Forecasts

Cone and track of tropical storms, tsunami arrival times, and active fires seen by satellite (tick them on the map).

Notifications

For accounts, by invitation, with a passkey, no password or email: one alert per area and level, and at night only red alerts.

No ads, no audience measurement, no third-party script or font; the only cookie remembers the language.

Hazards and sources

Natural disasters: earthquakes, tsunamis, volcanoes, cyclones, tornadoes, floods, extreme rain, wildfires and solar storms. Sources: USGS, EMSC, GDACS, USGS Volcano, NHC, NOAA SWPC, NASA FIRMS.

Official weather warnings, in green, yellow, orange and red (wind, rain, thunderstorms, snow and ice, heat, cold, floods, avalanches, coastal, fire, fog):

  • MeteoAlarm (EUMETNET) for 37 European countries;
  • Deutscher Wetterdienst (Germany), AEMET (Spain), Vigicrues (floods in France);
  • Environment and Climate Change Canada, NWS/NOAA (United States), MetService (New Zealand);
  • the services of the WMO register for Algeria, Argentina, Barbados, Jamaica, Mexico and the Philippines;
  • tsunami messages from the NOAA warning centres.

When a country is not covered, the reason is shown (for instance a license that forbids redistribution). The full list, with licenses, is on the sources page.

Four ways to use it

The website

Maps, country pages, "Near me", accounts and notifications. SvelteKit and MapLibre, OpenFreeMap base map.

vigie-web on GitHub

The API

All sources in one format: GeoJSON, CAP 1.2, JSON, and a compact frame for small screens. An unknown value stays empty, never made up. Python and FastAPI.

vigie-api on GitHub

Home Assistant

An integration (through HACS, as a custom repository): highest warning level, active warning, start, upgrade and end events, strongest earthquake near the house. No key needed.

A standalone alert screen, without Home Assistant, for the 7-inch Waveshare ESP32-P4: world map, the 5 most severe hazards with distance and direction, weather. ESPHome and LVGL.

The public API

The public instance is at https://vigie.auxfilsdesidees.fr/v1, read only. A few routes:

  • /v1/point?lat=…&lon=…: warnings, nearby hazards and weather for a place;
  • /v1/vigilances and /v1/vigilances.geojson: current warnings;
  • /v1/geojson/hazards: current disasters; /v1/cap/alerts: the same in CAP 1.2;
  • /v1/earthquakes, /v1/fires, /v1/history;
  • /v1/stream: a WebSocket to receive new alerts.

Limits per address: 300 requests per minute, and 10 per minute (120 per hour) on /v1/point. You can also host your own instance: the code is MIT licensed; the data keeps its source's license.

Experimental: a pre-alert for Turkey

Turkey has no reusable official feed. At the request of a user of the Home Assistant display, Vigie computes an unofficial pre-alert per province from the ECMWF model, available only in the API and as an option in the Home Assistant integration. Over the test year it caught 63% of episodes on the day and 71% the day before, and no wind episode: it in no way replaces the warnings of the Turkish weather service.
